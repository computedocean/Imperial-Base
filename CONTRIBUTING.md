# Contributing

Thanks for your interest in Imperial Base. Bug reports, ideas and pull requests are welcome.

## Getting set up

You need Windows 10 or 11, Node.js 20 or newer and Python 3.11 or newer.

```bat
git clone https://github.com/computedocean/Imperial-Base.git
cd Imperial-Base
start.cmd    :: first run: creates the Python environment, installs dependencies, builds the frontend
stop.cmd
dev.cmd      :: backend with auto-reload on :8742 + Vite hot reload on http://127.0.0.1:5273
```

The 3D models are generated by the Blender scripts in `tools/blender/`; see its [README](tools/blender/README.md).

## Before you open a pull request

1. Run `test.cmd`. It runs pytest, vitest and the TypeScript typecheck, and must end with `ALL TESTS PASSED`.
2. Add or update tests for behaviour you change. Pure logic lives in small, separately tested modules
   (for example `aircraft/flight.ts`, `personnel/duelMoves.ts`).
3. Update the documentation in `docs/` when you change behaviour, the API or the event format.
4. Keep the privacy rules: the hook must never store tool inputs or outputs, file contents, full commands or full
   prompts. See [Agent integration](docs/AGENT_INTEGRATION.md).

## Conventions

- **Windows file names are case-insensitive.** Do not put `walker.ts` next to `Walker.tsx`; give pure-logic
  modules a distinct name (`walkerGait.ts`).
- **Commit messages** start with a short sentence in the imperative ("Add the speeder bike patrol."), followed by
  bullet points when the change has several parts.
- **Assets** must be original or under a licence that allows redistribution (for example CC0). Note the source in
  the README's credits.

## Reporting bugs

Open an issue with what you did, what you expected and what happened, plus your browser, GPU and the quality
preset. Security problems go through the [security policy](SECURITY.md) instead.
